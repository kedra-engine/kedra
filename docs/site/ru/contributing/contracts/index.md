# Инженерные контракты

Выберите контракт поведения, которое вы меняете.
Для изучения и использования Kedra откройте [руководство](../../manual/introduction/index.md),
для поиска интерфейсов — [справочник API](../../api/index.md).
Эти контракты описывают инварианты, полномочия, поведение при ошибках и границы проверок.
Правила репозитория, ADR, юридические тексты и API крейтов/модулей остаются
авторитетными источниками.

| Изменить компоновку, установленные ресурсы, упаковку или оркестрацию релизов | [Распространение](distribution.md) |

Расположение реализации и сохраняемые правила репозитория описаны в
[карте кодовой базы](../codebase-map.md), команды ревью — в
[тестах и ревью](../tests-and-review.md).
Чтение исходников, компиляция, внедрённый ввод, физический ввод и сравнение изображений
доказывают разное. Описанный контракт не доказывает текущую нативную приёмку.
