# Справочник Luau API

API Kedra, предоставляемый хостом, поддерживает игровые скрипты, диагностику и автоматизацию.
Его интерфейсы нестабильны. Стандартная библиотека описана в справочнике самого Lua/Luau.
Английская версия каноническая.

## Выберите задачу

| Я хочу… | С чего начать | Что доступно сейчас |
| --- | --- | --- |
| Написать игровое поведение | [Игровые скрипты](game-host.md) | Behavior, конечные Sequence и явно подключаемые операции с живыми объектами |
| Автоматизировать редактор | [Диагностика редактора](editor.md) | Наблюдения без изменения данных в именованных debug-программах, не плагины проекта |

## Общая основа

Все эти задачи используют один [справочник runtime](runtime.md): точки входа, параметры,
ожидания, логи, события и дочерние Sequence. Для чтения сигнатур служат
[соглашения о контексте и значениях](conventions.md). Доступные возможности зависят от хоста.

Первое объяснение и полный пример переключателя находятся в
[руководстве программирования](../../manual/programming/luau.md). Ищите в справочнике
сигнатуры, результаты и ошибки, а в руководстве — настройку и пошаговые объяснения.

## Доступность и проверка

Общий runtime и разрешённые операции с живыми объектами доступны в release. Автоматизация
приложения и регистрации диагностики редактора требуют `debug_assertions`; нативный сценарий
`luau` выбирает тест, а не включает возможность Cargo.

Универсального `ctx.game`, загрузчика плагинов редактора, автоматического выполнения кода
проекта и Play внутри редактора нет. См. [ограничения реализации](limitations.md):
необязательная цель, геометрия стенда и лимиты ресурсов.

Примеры ссылаются на исходники. Нативный ввод и отрисованные кадры проверяйте отдельными
нативными тестами.
