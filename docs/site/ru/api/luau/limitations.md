# Ограничения реализации

Учитывайте привязку цели, геометрию и лимиты ресурсов вместе с общими
[соглашениями о контексте](conventions.md) при использовании API хоста.

## Аннотация привязки Behavior

`BehaviorContext.entity` необязателен: Rust `start` допускает непривязанный Behavior.
Только `attach` предоставляет цель. Исключите nil перед операцией с собственным
объектом. `TransformContext` и `UiContext` описывают хосты, гарантирующие привязанную
цель; одна аннотация типа её не предоставляет. Исходники:
`crates/kedra_script/types/runtime.d.luau`, `src/lib.rs` и `src/vm.rs` в этом крейте.

## Геометрия тестового стенда

`tests/fixtures/test_project/scripts/Native/remote.luau` проверяет высоту выражением
`rect[4] - rect[2]`, ширину — `rect[3] - rect[1]`, ожидая 64 и 120 логических пикселей
соответственно. Прямоугольник `{left,top,right,bottom}` индексируется от единицы; индекса 0 нет.
Размеры этого стенда не являются общими гарантиями UI API. Проверяйте их в нативном запуске,
а не только по выражениям в исходнике.
[Справочник приложения](application.md#идентификаторы-геометрия-и-узлы)
описывает правила геометрии.

## Уточнения контрактов

[Контракт функций приложения](application.md#публичные-функции) описывает выбор первого
`PrimaryWindow`, а не проверку уникальности нативных маркеров основного окна.
[Контракт ресурсов runtime](runtime.md#время-жизни-и-лимиты-ресурсов) отличает терминальные
прерывания по времени обработчика от перехваченных ошибок выделения памяти. Эти правила действуют
независимо от аннотаций типов.
