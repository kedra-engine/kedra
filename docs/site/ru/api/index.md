# Справочник API: Rust и Luau

## Выберите задачу

[Справочник Luau](luau/index.md) доступен в обычной сборке сайта:

| Задача | С чего начать |
| --- | --- |
| Писать игровые скрипты | [Игровые скрипты](luau/game-host.md) и [операции с живыми объектами](luau/bevy.md) |
| Наблюдать состояние редактора | [Диагностика редактора, не плагины](luau/editor.md) |
| Управлять debug-приложением | [Автоматизация приложения](luau/application.md) |
| Поддерживать тестовый сценарий | [Тестовые стенды](luau/testing.md) |
| Устанавливать и разрешать Luau из Rust | [Нативная интеграция](luau/integration.md) |

[Runtime](luau/runtime.md), [соглашения](luau/conventions.md) и
[ограничения реализации](luau/limitations.md) относятся к API всех хостов.
Это возможности, установленные хостом, а не универсальный игровой SDK. Страницы Luau
входят в EN/RU поиск сайта вместе с руководством.

Для интеграции Rust используйте инструкцию по сгенерированному справочнику ниже.
Контекст сценариев описан в [Программировании](../manual/programming/index.md),
а изменение Kedra — в [руководстве участника](../contributing/index.md).

## Руководство по Rust API

Справочник Rust API генерируется из комментариев Rust в текущей рабочей копии.
Идентификаторы и контракты остаются на английском: это не перевод API и не
отдельно размещённая документация релиза. API и форматы исходников Kedra нестабильны.

## Открыть сгенерированный справочник

Список библиотек в конце страницы содержит ссылки на крейты только в полной
сборке. Обычная сборка без Rust вместо них объясняет отсутствие rustdoc.

Из корня репозитория, после установки зависимостей документации:

```sh
cd docs
bun run build:api
bun run preview
```

Откройте эту страницу в локальном предпросмотре на loopback-адресе. Страницы rustdoc
находятся под `/api/` и сохраняют собственную навигацию и английский поиск API.
Они не входят в поиск двуязычного руководства. Для возврата используйте кнопку
«Назад» браузера. `bun run build` создаёт быстрый предпросмотр без Rust, включая Luau,
и удаляет из него сгенерированный rustdoc. Не запускайте две сборки одновременно.

## Область и контракт возможностей

Полная сборка требует закреплённого в репозитории набора инструментов Rust, системных
зависимостей нативной сборки и зависимостей из Cargo.lock. Она выполняет:

```sh
cargo doc --workspace --no-deps --all-features --locked
```

Интеграция добавляет изолированный `--target-dir target/documentation/cargo` и
запрещает предупреждения и неработающие ссылки между элементами API, как проверка rustdoc в
репозитории. Версии берутся из метаданных Cargo текущей рабочей копии и не означают
публикацию релиза. Ниже перечислены все библиотеки рабочего пространства; Cargo
также генерирует документацию его бинарных целей. Документация внешних зависимостей
не включена: часть ссылок rustdoc ведёт на сайты разработчиков зависимостей и требует сети.

Документация собирается со всеми Cargo features для платформы хоста и включёнными
отладочными проверками. Такая сборка не проверяет обычную, минимальную, release-сборку
или другие сочетания платформ и возможностей. Например, `kedra_scene/render`,
`kedra_assets/model-support` и `kedra_ui/text-capture` открывают дополнительные
возможности. Перед использованием читайте контракты крейта и требования к его возможностям.
Наличие API в справочнике не даёт приложению прав на операции среды выполнения или редактора
и не реализует Play или Save исходников.

## Результат и лицензии

Сгенерированный предпросмотр находится в `target/documentation/site/`, а не в
авторских исходниках. При ошибке полной сборки этот предпросмотр удаляется, чтобы
не показывать устаревший или частичный API. Изолированный кеш Cargo остаётся для
повторного запуска; обычный каталог `target/doc/` интеграция не изменяет.

Предпросмотр добавляет проверенные якоря диапазонов вокруг реальных номеров строк,
сохраняя ссылки rustdoc и JavaScript-подсветку исходников. Ограниченный адаптер
также исправляет шесть форм унаследованных ссылок на проверенные страницы зависимостей
закреплённых версий. Меняется только скопированный HTML, а не исходная документация
Cargo, код, скрипты поиска или лицензионные ресурсы. Непроверенные версии инструментов
и зависимостей или несовместимая форма известного HTML останавливают полную сборку.

При копировании полного предпросмотра сохраняйте весь каталог `api/`. Статические
ресурсы rustdoc содержат собственные файлы copyright и лицензий, включая шрифты
под SIL Open Font License и атрибуцию логотипов Rust. Файл руководства
`third-party-notices.txt` эти ресурсы не покрывает. Тексты лицензий Kedra MIT и
Apache-2.0 копируются рядом с API. Сборка для публикации включает этот полный справочник;
отдельные снимки документации для выпусков не настроены.
