# Поддерживаемые форматы и настройки обработки

Инструменты обработки ассетов Kedra принимают перечисленные ниже форматы и настройки.
Другие форматы и возможности Bevy не поддерживаются автоматически, а у превью редактора
есть дополнительные ограничения. Инициализация сохраняет настройки в существующих метаданных.

## Обработка исходников по умолчанию

| Исходник | Действие `assets init` по умолчанию | Важное ограничение |
| --- | --- | --- |
| `.svg` | Обработка `SvgToImage` | Одно изображение Bevy на основе PNG, не векторная графика в runtime |
| `.png` | Нативный `ImageLoader` | Некорректные байты изображения приводят к сбою сборки |
| `.glb` | Нативный `GltfLoader` | Допуск GLB/glTF 2.0; камеры, свет и анимации по умолчанию отключены |
| `.ttf`, `.otf` | Нативный `FontLoader` | Данные шрифта проверяются; обязательные лицензии поставляются отдельно |
| `.css` | `CssStyleSheetLoader` Flair | Строгий режим `ReturnError`; исходник не более 64 КиБ |
| `.scene.ron`, `.prefab.ron` | `DocumentLoader` | Разбор документа; UUID документа и метаданных должны совпадать |
| `.prefabs.ron` | `CatalogLoader` | Каталог источников сцен/префабов, не манифест поставки |
| `.environment.ron` | `EnvironmentLoader` | Данные окружения версии 1; загрузчик с ограничением размера |
| Прочие `.txt`, `.json`, `.ron` | `DataLoader` | Непрозрачные байты, без автоматического предметного разбора |
| Другие расширения | `Ignore` | Не входят в итоговую поставку |

Специализированные загрузчики суффиксов RON имеют приоритет над общим загрузчиком данных.
Одно лишь расширение `.json` или `.ron` не проверяет содержимое как конфигурацию проекта
или сцену. Импорты CSS должны разрешаться через проверенный источник; некорректный CSS
или отсутствующий импорт приводят к сбою нативной проверки загрузки во время сборки.
Метаданные CSS с режимом восстановления после ошибок не допускаются.

Поля документов описаны в [справочнике исходников сцен](../scenes/index.md#поля-документа),
а каталоги `.prefabs.ron` — в
[подготовке приложения](../scenes/lifecycle.md#подготовьте-приложение).

В готовом тестовом проекте есть примеры: `checker.png`, `ship.glb`, `preview.css`,
`day.environment.ron` и `Fixture-Inter.ttf` в `tests/fixtures/test_project/assets`.
Текстовые файлы для проверок браузера с авторскими метаданными `Ignore` остаются
в перечне исходников, не становясь ассетами поставки. Соберите этот набор без изменений
по [инструкции обработки](pipeline.md).

## Варианты SVG-изображений

`SvgToImage` и `SvgToImageVariants` используют общие настройки:

- `size: None` берёт размер из SVG; `Some([width, height])` задаёт логические пиксели.
- `densities` — непустой строго возрастающий список целых чисел от 1 до 8.
- Каждый результат растеризации должен содержать 1–16 777 216 пикселей; размеры ненулевые.
- Внешние файлы изображений и шрифтов не загружаются. SVG должен быть самодостаточным.

`SvgToImage` требует ровно `densities: [1]` — это значение инициализации по умолчанию.
`SvgToImageVariants` создаёт родительский ассет `ImageVariants` с нативными изображениями
под метками вроде `#1x` и `#2x`. Запрашивайте только метки, включённые в пакет; удерживайте
дескриптор родителя или изображения, пока ресурс используется.

Реальный пример настроек: `assets/editor/icons/spinner.svg.meta` выбирает
`kedra_import::processors::SvgToImageVariants` с таким значением настроек:

```ron
(size: None, densities: [1, 2, 3, 4])
```

Это фрагмент настроек, а не полный файл метаданных. При изменениях в отдельной копии
исходников сохраняйте существующий UUID и нативную оболочку метаданных. После обработки
`editor://icons/spinner.svg#2x` адресует изображение 2x, хотя физический путь в поставке
сохраняет `.svg`. Обработанный загрузчик выбирается нативными метаданными.

Новые пакеты вариантов используют версию 2 с PNG без потерь в кодировке Base64; runtime
также читает версию 1 с числовыми массивами байтов. Это не сжатие текстур для GPU,
не автоматический выбор DPI и не автоматическое создание всех плотностей от 1 до 8.

Готовые значки редактора используют плотности 1x–4x. Решение о формате и обоснование
совместимости остаются в [ADR 0022 (на английском)][compact-images].

## Шрифты и лицензии

Шрифты и обязательные тексты их лицензий — отдельные ассеты поставки. Сохраняйте эти тексты
при распространении ресурсов; успешная загрузка шрифта не подтверждает права на него.
Точные идентичности исходников, лицензии и преобразования указаны в
[сведениях о происхождении ассетов (на английском)][provenance].
Подмножества не гарантируют поддержку всех письменностей
Unicode; отсутствующие глифы требуют осознанного выбора лицензированного шрифта/fallback
и нативной проверки.

## Допуск GLB и отображение в редакторе

Контейнер модели — двоичный GLB с версией ассета glTF `2.0`. JSON `.gltf` не допускается
как замена, даже если в метаданных указан нативный загрузчик glTF.
Перед нативной загрузкой проверяются условия:

- Нет нескольких родителей, повторяющихся рёбер и циклов, включая несвязанные узлы.
- В пути от корня до листа не более 128 узлов.
- Отдельные пределы: 4096 узлов, 4096 примитивов мешей и 4096 нативных сущностей всех сцен.

Развёртывание учитывает каждый контейнер сцены, повторный корень или поддерево, экземпляр
примитива и возможный дочерний источник света независимо от флагов нативного загрузчика.
Корректные контрольные суммы не обходят эти структурные ограничения. Сборка проверяет GLB,
даже если в метаданных указано `Ignore`; сигнатура GLB и метаданные нативного загрузчика glTF
также включают проверку после переименования файла. Геометрия, буферы, текстуры и настройки
по-прежнему требуют обычной проверки нативным загрузчиком.

Эти условия допуска не обещают полную поддержку моделей в редакторе. Прямое превью GLB
использует `Scene0`; импортированные камеры, свет и анимации отключены, скины и морфы
отклоняются. У отображения есть дополнительные ограничения. Успешная проверка ассета
не доказывает, что модель отобразится в любом представлении редактора.

## Ограничения поставки и чтения

Точная сериализация `kedra-assets.json` должна укладываться в 64 КиБ. Для файла данных
можно заявить не более 256 МиБ, для `.meta` — не более 64 КиБ. Проверенный источник
ограничивает чтение до вычисления хеша, отклоняет незаявленные ресурсы и не предоставляет
общий перебор каталогов файловой системы. Нативные файлы должны разрешаться в обычные
файлы внутри канонического корня поставки; выходящие наружу символические ссылки и специальные
файлы отклоняются. Не меняйте зарегистрированные поставки.

Ошибки на этих границах разобраны в [решении проблем](troubleshooting.md).
