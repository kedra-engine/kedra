# Что такое Kedra?

Kedra — открытая среда разработки игр на базе Bevy. Её цель — связать данные проекта,
ассеты, сцены, переиспользуемые префабы, программирование и нативный редактор в единый
рабочий процесс, сохранив возможность обычной разработки на Bevy.

Редактор — видимая рабочая среда, но не весь продукт. Общие runtime-сервисы загружают
контент в приложениях; инструменты авторинга управляют редактируемыми исходниками;
инструменты командной строки готовят ассеты и собирают отдельные приложения. Эти части
используют общие данные, а работающему приложению не требуется установленный редактор.

## С чего начать: верные ожидания

Kedra находится на ранней стадии разработки. Сейчас она полезна для знакомства с моделью
проектов и контента, изучения поддерживаемых материалов и разработки интеграций на базе
общих Rust-механизмов. Это ещё не полный игровой SDK и не визуальная среда создания игр
с законченным рабочим циклом. API и форматы исходников нестабильны.

Можно создать или открыть проект, просмотреть его исходники, открыть поддерживаемые сцены
и префабы, изучить их иерархию и значения компонентов. При явно указанной соответствующей
поставке ресурсов Scene View отображает поддерживаемые пространственные/UI-документы
и превью PNG и статических GLB. Это работа только для чтения: перемещение камеры или
выбор объекта не меняют документ, а отрисованное превью не запускает игровой код проекта.

Визуальное редактирование сцен, изменение полей документа, сохранение документов
в редакторе, загрузка кода проекта и Play не реализованы. Существующие Rust API изменения
исходников, сборки и скриптов — основа для этих процессов, но не их замена.

## Для кого подходит текущая реализация?

- **Для любознательных разработчиков**, которые хотят понять, как среда на базе Bevy
  связывает исходники, runtime-данные и представления редактора.
- **Для разработчиков на Rust и Bevy**, оценивающих сервисы сцен, ассетов, скриптов
  или приложений в явно настроенном ими приложении-хосте.
- **Для первых участников разработки**, которые помогают создать связный процесс
  авторинга и готовы разбираться с неподдерживаемым контентом и неполной нативной приёмкой.

Если вам нужно уже сегодня собрать, сохранить и запустить полноценную игру целиком
в редакторе, Kedra пока не предоставляет такого цикла. Но для изучения понятий не нужно
сначала разбираться в структуре крейтов: руководство начинает с пользовательской модели,
а не с деталей API.

## Простой пример

Представьте сцену с двумя экземплярами переиспользуемого префаба параллелепипеда. Проект
хранит исходники сцены и префаба, а также текстуру, на которую они ссылаются. Инструменты
ассетов готовят поставку ресурсов для загрузки приложением. Система сцен превращает
экземпляры префаба в обычные сущности Bevy; редактор строит отдельное представление
поддерживаемого контента только для чтения.

Два экземпляра могут использовать общий исходник префаба, но иметь разные дескрипторы
живых сущностей. Изучение экземпляра не переписывает префаб. Это ключевое разделение
в Kedra: редактируемые исходники описывают замысел, а загруженные экземпляры и представления
редактора решают разные задачи.

Структура документов и композиция описаны в разделе
[Сцены и префабы](../scenes/index.md).

## Выберите маршрут по руководству

- Впервые знакомитесь со средой? Прочитайте [Карту продукта](product-map.md) о ролях
  редактора, runtime и инструментов, затем [Начало работы](../getting-started/index.md).
- Уже используете Bevy? Раздел [Kedra и Bevy](kedra-and-bevy.md) объясняет, что остаётся
  стандартным Bevy, а что добавляет Kedra.
- Оцениваете рабочий процесс? Сначала проверьте [Текущие возможности](capabilities.md),
  чтобы не принять цель развития за доступную функцию.
- Изучаете контент? Продолжите разделами [Ассеты](../assets/index.md)
  и [Сцены и префабы](../scenes/index.md).

Проверяйте нативное взаимодействие на целевой машине: одного изучения кода недостаточно.
Ввод, IME и работа с мониторами разной плотности ещё не сертифицированы для набора
настольных платформ. Linux, Windows
и macOS — направления для настольных систем; runtime для веба и Android/iOS — будущая работа.
