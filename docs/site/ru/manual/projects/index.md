# Проекты

Проект — это каталог исходных данных Kedra для авторинга, обозначенный файлом `kedra.toml`.
Он задаёт постоянную идентичность проекта, отображаемое имя и каталог исходников ассетов.
Откройте проект, чтобы просматривать исходники и изучать поддерживаемые сцены, префабы и ассеты.

Создание проекта не создаёт готовую к запуску игру. Сейчас редактор не компилирует и не выполняет
код проекта, не предоставляет Play, визуальное редактирование сцен или сохранение документов.

## Что входит в проект?

Только что созданный проект имеет следующую структуру:

```text
My Game/
├── kedra.toml
└── assets/
```

Каталог ассетов изначально пуст. Создание не добавляет сцену, префаб, Cargo-пакет,
точку входа скрипта или обработанную поставку ресурсов. В проекте могут находиться другие файлы,
но само их наличие не означает, что редактор умеет их выполнять.

При копировании наполненного проекта сохраняйте исходные файлы вместе с существующими
сопутствующими файлами `.meta`. Они содержат идентичность ассетов и настройки обработки,
а не временные пользовательские настройки. Обработанные поставки ресурсов и локальные настройки
редактора выполняют другие задачи, чем исходники.

## Манифест проекта

Полный манифест тестового проекта хранится в репозитории по пути
`tests/fixtures/test_project/kedra.toml`:

```toml
id = "7e570000-0000-4000-8000-000000000000"
format = 1
name = "Kedra Test Project"
editor_version = "0.1.3"
assets = "assets"
```

Это идентичность существующего проекта, а не UUID-шаблон для новых проектов.
Чтобы получить новую идентичность, используйте **New project**.

| Поле | Значение |
| --- | --- |
| `id` | Постоянный ненулевой UUID проекта; перемещение каталога его не меняет. |
| `format` | Версия схемы проекта на диске. Сейчас поддерживается только `1`. |
| `name` | Понятное человеку имя проекта, не имя Cargo-пакета или исполняемого файла. |
| `editor_version` | Информационная версия записавшего редактора; не должна быть пустой. Открытие её не обновляет. |
| `assets` | Существующий каталог ассетов относительно корня проекта. |

Все пять полей обязательны; неизвестные поля отклоняются. Манифест должен быть корректным
TOML в UTF-8 размером не более 64 КиБ. Совместимость определяется полем `format`,
а не `editor_version`: другая версия записавшего редактора сама по себе не мешает открыть
проект формата 1. Автоматической миграции неподдерживаемых форматов нет.

Значение `assets` может указывать на вложенный каталог, но не может быть пустым, абсолютным
или содержать переходы к родительскому каталогу. После разрешения ссылок файловой системы
каталог должен оставаться внутри корня проекта. Относительные пути в манифесте отсчитываются
не от рабочего каталога терминала.

## Открытие не означает полную проверку содержимого

При открытии проекта проверяются манифест и расположение каталога ассетов. Это не доказывает,
что все исходные документы корректны и все ассеты готовы к отображению.

Когда вы открываете поддерживаемый исходник через Asset Browser, редактор проверяет набор
исходников и загружает его в общую рабочую область проекта. На этом этапе
проверяются документы и ссылки. Поэтому некорректный документ в другой части набора может
помешать загрузке, даже если сам проект уже успешно открылся.

Отображение — отдельный этап: Scene View и поддерживаемые превью ассетов требуют явно заданную
проверенную поставку ресурсов проекта, соответствующую исходникам. Открытие не собирает такую
поставку и не разрешает выполнение кода. Успешный просмотр исходника не означает доступность Play.

## Перемещение и передача проекта

Перемещайте каталог проекта целиком, сохраняя манифест, относительный каталог ассетов и `.meta`.
UUID проекта в манифесте останется прежним, а нативное расположение изменится.
Если запись недавнего проекта указывает на старое место, откройте новое через **Open folder**.
История недавних проектов — локальные настройки, а не переносимый индекс проектов
или резервная копия.

Копирование каталога также копирует его идентичности. Это удобно для неизменённой рабочей копии,
но не создаёт независимый проект и не переназначает идентичности автоматически.
