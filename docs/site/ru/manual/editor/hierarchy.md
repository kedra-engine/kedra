# Hierarchy

Hierarchy показывает **граф композиции исходников** активной сцены или префаба: корень,
локальные узлы, унаследованное содержимое, переопределения и вложенные экземпляры префабов.
Это не список всех runtime-сущностей, вспомогательных объектов превью, частей импортированной
модели или элементов редактора.

Сначала откройте сцену/префаб из [Assets](asset-browser.md). Успешное открытие выбирает корень;
переключение вкладок меняет дерево и восстанавливает выбор соответствующего документа.
Hierarchy остаётся доступной, даже если Scene View не может отрисовать документ.

## Навигация и выбор

Изначально ветви раскрыты. Щёлкните строку имени, чтобы выбрать узел; кнопка раскрытия
только сворачивает/раскрывает ветвь. Выбор общий со Scene View и незаблокированным Inspector.
Это не редактирование; выбор узла не перемещает камеру превью.

| Действие | Результат |
| --- | --- |
| Up / Down | Выбрать предыдущую/следующую видимую строку. |
| Home / End | Выбрать первую/последнюю видимую строку. |
| Left | Свернуть раскрытую ветвь; иначе выбрать родителя. |
| Right | Раскрыть свёрнутую ветвь; иначе выбрать первого видимого потомка. |
| Вертикальная полоса прокрутки | Дойти до строк вне текущей области просмотра. |
| Горизонтальная прокрутка | Дойти до содержимого с глубокой вложенностью. |

Фокус клавиатуры и выбор различаются. Перевод фокуса не меняет выбранный узел,
но делает его выделение неактивным. Сворачивание ветви не сбрасывает выбранного потомка.
Панель отображает нужные видимые строки по мере навигации, а не отбрасывает конец
большого принятого графа.

Корни экземпляров обозначены значком ссылки. Одинаковые имена не делают узлы одним объектом:
при выборе учитывается вся цепочка вложенных экземпляров. Значки обычных ветвей и узлов
не обозначают меши и не определяют типы компонентов узла.

## Поиск и переход к выбранному

Откройте поиск через **… → Search nodes** или Ctrl/Cmd+F с фокусом в Hierarchy.
Изначально строка поиска скрыта. Поиск сопоставляет имена с Unicode-приведением регистра,
сохраняя предков как приглушённый контекст, включая совпадения внутри свёрнутых ветвей.

- Фильтрация не меняет выбор документа, даже если выбранная строка исчезла.
- Закройте поиск его кнопкой или Escape в поле. Это очищает запрос и восстанавливает
  обычное состояние раскрытия и прокрутку до фильтрации.
- **… → Reveal selected node** очищает запрос, раскрывает предков выбранного узла,
  прокручивает к нему и устанавливает фокус на его строку.
- **… → Toggle source details** показывает дополнительные сведения об имени, исходнике
  и идентичности с учётом области экземпляров.

Поиск ограничен 256 символами и отклоняет управляющие символы. Дополнительный фильтр
в строке поиска отключён; фильтров по типу узла/компонентам нет.
Меню **…** — общее меню dock-группы, а не структурное контекстное меню узла.

Раскрытие, фильтр и прокрутка сохраняются для каждого документа в течение сеанса,
в том числе при Hide/Reopen, Float/Redock и Reset. Не рассчитывайте на их восстановление
после перезапуска редактора.

## Пример: одинаковые узлы разных экземпляров

Подготовка тестового проекта описана в [первом документе](../getting-started/first-document.md).
Идентичность в области экземпляра объясняет раздел
[Сцены и префабы](../scenes/index.md#идентичность-и-ссылки).

В тестовом проекте из репозитория есть `assets/Hierarchy/Main.scene.ron`. Откройте его из Assets:

1. Убедитесь, что выбран корень **Main scene**.
2. Откройте **Search nodes** и найдите `STRASSE`.
3. В дереве композиции будут два совпадения **Straße leaf** в разных экземплярах.
4. Выберите первое, затем второе. Выбранный узел изменится, хотя показанное имя останется тем же;
   **Toggle source details** помогает различить адреса.
5. Найдите `nothing matches`. Дерево покажет отсутствие совпадений, сохранив второй выбор.
6. Вызовите **Reveal selected node**, чтобы убрать фильтр и вернуться к этому экземпляру.

Пространственный пример: откройте `Composed.scene.ron` и выберите **Warm sphere**.
Inspector покажет исходные компоненты узла, а готовый Scene View — рамку выбора.
Для перемещения камеры используйте **Frame selection** в Scene View, а не повторный выбор.

## Пустые состояния и ошибки

Без активного исходного документа Hierarchy подсказывает открыть его. Активация превью
PNG/GLB также оставляет панель без графа документа. Документ только с корнем — другое
состояние: он показывает один настоящий узел, даже без компонентов и потомков.

Открытие исходника, отсутствие совпадений и ошибка открытия имеют разные сообщения.
Неудачное открытие сохраняет прежний документ, дерево и выбор, указывая сохранённое дерево
в диагностике. Некорректный исходник может помешать принятию до появления дерева;
редактор не подставляет иерархию по умолчанию.

Навигация только для чтения не позволяет переименовывать, создавать, удалять, дублировать,
переподчинять или перетаскивать узлы и распаковывать префабы. Активных структурных команд
узлов и Save нет. Композиция ограничивает эффективный граф 4096 узлами: это предел отказа,
а не обещание загрузки файлов любого размера. См. [композицию](../scenes/composition.md).
