# Asset Browser

Панель **Assets** показывает каталог исходных ассетов открытого проекта. Найдите файл
или папку, затем явно откройте сцену, префаб, PNG или статический GLB. Просмотр и открытие
не создают sidecar-файлы, не собирают ресурсы, не записывают исходники и не запускают
внешнюю программу.

## Переход по папкам исходников

Щёлкните папку в левом дереве, чтобы войти в неё. Кнопка раскрытия разворачивает или
сворачивает ветвь без перехода. В области содержимого один щелчок выбирает папку,
двойной щелчок или Enter открывает её. Сегменты цепочки пути переходят к нужному предку.

| Действие | Поведение |
| --- | --- |
| Back / Forward | Возврат к успешно посещённым папкам с их поиском, выбором и прокруткой. |
| Up | Переход к родительской папке, но не выше корня исходников. |
| Backspace на элементе содержимого | Переход на папку вверх. |
| Up/Down/Home/End на строке дерева | Перевод фокуса между видимыми папками с прокруткой к строке. |
| Left/Right на строке дерева | Свернуть/раскрыть или перейти к родителю/потомку уже свёрнутой/раскрытой ветви. |
| Enter на кнопке перехода в папку в фокусе | Войти в эту папку. |
| Нативные полосы прокрутки | Независимая прокрутка дерева и содержимого перетаскиванием ползунка или щелчком по дорожке. |

Папки идут перед файлами, далее используется точное системное имя. Sidecar-файлы `.meta`
не показаны отдельными элементами. Строка состояния использует пути относительно проекта,
например `assets/Composed.scene.ron`, а не абсолютные пути файловой системы.

Статус **untracked (no sidecar)** означает, что рядом не обнаружен обычный sidecar-файл
`.meta`, не являющийся символической ссылкой. Статус не различает все ошибки файловой системы
и не проверяет метаданные. Сам признак tracked не доказывает корректность метаданных
или пригодность поставки. Браузер не исправляет метаданные; превью PNG/GLB требует
принятой идентичности и ресурсов.

## Поиск и режим представления

Введите запрос в поле или нажмите Ctrl/Cmd+F, когда фокус находится внутри Assets.
Поиск сопоставляет имена **только текущей папки** с Unicode-приведением регистра.
Он не просматривает вложенные папки или содержимое файлов. Кнопка очистки удаляет запрос.

Фильтр сцен/префабов оставляет папки видимыми, а среди файлов показывает только `.scene.ron`
и `.prefab.ron`. Отключите его, чтобы видеть PNG/GLB и другие исходники. Сетка и список
показывают те же элементы и выбор; значки обозначают типы исходников, а не отрисованные
миниатюры. Режим сетки/списка и фильтр типов общие для браузера, а не отдельные истории папок.

Когда элемент содержимого в фокусе, стрелки выбирают соседние элементы; Up/Down переходят
по строкам сетки или списка. Home/End выбирают первый/последний видимый результат
и прокручивают к нему. Фильтрация может скрыть выбранный элемент, не очищая его идентичность.
Строка состояния продолжает обозначать этот выбор: Open не подменяет его первым результатом.

Поиск принимает до 256 символов и отклоняет управляющие символы. Переходы по папкам,
поиск и прокрутка сохраняются при Float/Redock и Hide/Reopen в рамках сеанса.
После перезапуска редактор не восстанавливает историю навигации браузера.

## Открытие элемента

Один щелчок выбирает элемент; двойной щелчок или Enter активирует элемент в фокусе.
Можно также выбрать элемент и вызвать **… → Open selected source**. Результат зависит от типа:

| Элемент | Результат |
| --- | --- |
| Папка | Переход в папку. |
| `.scene.ron` / `.prefab.ron` | Принятие/активация вкладки документа только для чтения; сначала выбран корень. |
| `.png` | Превью изображения только для чтения с подходящими принятыми метаданными и поставкой ресурсов. |
| `.glb` | Превью статической модели только для чтения с подходящими принятыми метаданными и поставкой ресурсов. |
| Другой исходный файл | Сообщение о неподдерживаемом типе; другое приложение не запускается. |
| Ссылка, специальный файл или элемент с недопустимым именем | Отказ в открытии с диагностикой. |

Открытие документа проверяет общий набор исходников, а не только видимое имя файла.
Некорректный или неподдерживаемый документ в другом месте может помешать принятию набора.
Просмотр допустимого исходника не требует успешного превью. Дополнительные требования
к отрисовке описаны в разделах [сеансов документов](index.md#source-sessions-and-external-changes)
и [Scene View](scene-view.md).

**New** и **Import** отключены; причина показана при наведении. В панели нет создания,
обработки, переименования, перемещения, удаления, выбора ссылки или сохранения исходников.
Контекстное меню редактирования отдельного ассета не реализовано; меню **…** принадлежит
dock-группе и добавляет Open/Refresh, когда Assets — её активная вкладка.

## Пример: открытие проверенной сцены

Подготовка проекта описана в [первом документе](../getting-started/first-document.md).
Идентичность исходников и скрытые метаданные объясняет раздел [Ассеты](../assets/index.md).

В рабочей копии `tests/fixtures/test_project`:

1. Вернитесь к корню Assets и при необходимости отключите фильтр сцен/префабов.
2. Найдите `Composed.scene.ron` и выберите элемент одним щелчком.
3. Посмотрите путь/тип в строке состояния; активный документ пока не изменился.
4. Вызовите **Open selected source** или дважды щёлкните элемент.
5. Откроется вкладка **Composed spatial scene**, а её корень будет выбран в Hierarchy.
   Inspector покажет значения исходника; Scene View отрисует его лишь с подходящими ресурсами.

Пример только для поиска: `STRASSE` находит файл `Straße.txt` из тестового проекта. Его открытие
сообщает об отсутствии редактора документа, не выполняя и не изменяя файл.

## Загрузка, устаревшие списки и ограничения

Загрузка, пустая папка и отсутствие совпадений фильтра — разные состояния. Счётчик элементов
виден независимо от выбора. Подсказки объясняют длинные имена и недоступные действия.

После изменений файловой системы используйте **… → Refresh sources** или F5 с фокусом
в Assets. Неудачное обновление сохраняет прежний список как устаревший и блокирует
активацию до успешного чтения. Неудачное открытие сохраняет выбор браузера и прежний документ.

Список хранит до 512 элементов папки с указанием неполноты. Перечисление отклоняет папки
с более чем 4096 просмотренными элементами или 1 МиБ закодированных имён.
Дерево лениво читает раскрытые ветви и тоже имеет ограниченные кеши. Отсутствие файла
в неполном списке не доказывает, что файла нет; распределите содержимое по меньшим папкам
и обновите список. Ссылки не обходятся. Refresh не перезагружает принятый документ
и не расширяет принятый набор исходников.
