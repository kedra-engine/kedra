# Рабочее пространство редактора

Редактор — настольное рабочее пространство для просмотра исходников проекта, сцен,
префабов и поддерживаемых ассетов. Панели работают только для чтения: открытие проекта
не запускает его код, а перемещение камеры или панели не изменяет исходный документ.

Сначала [откройте проект](../projects/create-open.md). Примеры этого раздела используют
неизменённую рабочую копию `tests/fixtures/test_project` из репозитория.
Эти ассеты служат примерами, а не добавляются автоматически в новый проект.

## Выберите нужную панель

Подготовка тестового проекта и первое открытие описаны в
[первом документе](../getting-started/first-document.md).

В начальной компоновке Hierarchy находится слева, Inspector — справа, а Document Preview —
над Assets в центре. Это исходное расположение, а не ограничение.

| Панель | Назначение |
| --- | --- |
| [Assets / Asset Browser](asset-browser.md) | Переход по папкам исходников, поиск имён файлов и явное открытие исходника. |
| [Hierarchy](hierarchy.md) | Навигация по узлам композиции активного документа и выбор исходного узла. |
| [Scene View](scene-view.md) | Превью поддерживаемого содержимого, навигация пространственной камеры и выбор подходящих мешей. |
| [Inspector](inspector.md) | Просмотр эффективных значений компонентов выбранного исходного узла. |

Изначально Document Preview пуст. Открытие сцены или префаба создаёт вкладку документа
и скрывает этот пустой слот. Вкладка содержит Scene View, а не отдельное окно редактирования
сцены. PNG и статические GLB открываются в отдельных вкладках превью ассетов.

Элементы Play, Pause, Stop, Save, Build и глобального поиска в заголовке отключены.
Собирайте поставки ресурсов
[из командной строки](../assets/pipeline.md).

## Расположение панелей и вкладок

Любую панель или документ можно переместить, объединить во вкладки, отделить разделителем,
вынести в отдельное окно или скрыть. Зарезервированной центральной области для документов
нет. Команды находятся в меню **…** группы, а не в контекстном меню узла или ассета.

| Действие | Результат |
| --- | --- |
| Щелчок по вкладке | Активировать представление. |
| Перетаскивание подписи вкладки | Изменить порядок, добавить вкладку в другую группу или разделить группу у края. |
| Shift + перетаскивание подписи | Переместить всю группу, сохранив порядок и активную вкладку. |
| Отпускание в центре компаса | Добавить вкладки в целевую группу. |
| Отпускание на краю компаса | Разместить отдельную область слева, справа, сверху или снизу. |
| Перетаскивание разделителя | Изменить размеры соседних областей с учётом их минимальных размеров. |
| Двойной щелчок по разделителю | Восстановить предпочтительную пропорцию. |
| Escape при перетаскивании/изменении размера | Отменить ещё не применённое изменение компоновки. |
| Left/Right/Home/End на подписи вкладки в фокусе | Активировать предыдущую, следующую, первую или последнюю вкладку. |
| Стрелки на разделителе в фокусе | Изменить пропорцию. |
| Space/Enter на разделителе в фокусе | Восстановить предпочтительную пропорцию. |

Предпросмотр показывает, куда можно поместить панель; если размещение недоступно, указана
причина. Отпустите указатель над допустимой целью, чтобы применить изменение. Если панели
не помещаются или новая компоновка ещё не готова, действующее расположение не меняется.
Кнопки закрытия и меню группы не служат ручками перетаскивания. Если подписи не помещаются,
полоса вкладок прокручивается по горизонтали.

Меню **…** содержит **Maximize group** / **Restore group**, **Float group**,
**Float active tab**, **Hide group** и пункты вкладок группы. Разворачивание сохраняет
исходное разделение для Restore. В меню также можно прочитать обрезанное имя вкладки.

В отдельном окне команда **Redock to main window** возвращает группу в главное окно.
Если оконная система не позволяет выбрать цель перетаскивания между окнами, используйте
явные команды Float/Redock. Отделение сохраняет состояние панели, не создавая новый
сеанс исходников.

## Скрытие, повторное открытие и сброс

Кнопка закрытия вкладки скрывает представление, а не удаляет сеанс исходного документа.
Закрытие отдельного окна скрывает его представления; закрытие главного завершает редактор.
В **Panels** скрытые представления перечислены как **Show …**, видимые — как **Select …**.
Повторное открытие того же исходника из Assets также возвращает сохранённую вкладку.

**Reset layout** восстанавливает начальное расположение, не пересоздавая содержимое панелей.
Например, откройте `Composed.scene.ron`, выберите **Warm sphere** в Hierarchy и вынесите
Inspector командой **Float group**. Верните его и сбросьте компоновку: документ и выбор
сохранятся, а панели вернутся на исходные места.

Локальные настройки проекта хранят схему размещения, порядок вкладок, активные/развёрнутые
группы и положение окон. Это не сохранение документов. История переходов Assets и положения
камер — состояние сеанса, а не обещание восстановления после перезапуска процесса.
Восстановленные вкладки документов сначала служат неактивными заглушками: откройте исходники
через Assets для проверки их текущего состояния. Настройки не заменяют проверку содержимого.

Некорректные настройки сохраняются с сообщением об ошибке. Явный Reset оставляет отклонённые
данные под уникальным именем `*.rejected-*.json`. Если восстанавливаемое отдельное окно
не готово к работе, его представления возвращаются в главное окно с диагностикой,
а не исчезают.

## Общий выбор

Три действия имеют разный смысл:

1. **Выбор ассета в Assets:** указать файл или папку. Документ при этом не активируется.
2. **Открытие сцены/префаба или активация его вкладки:** выбрать документ для других панелей.
3. **Выбор узла:** изменить общий выбор исходного узла в этом документе.

В новом документе выбран корень. Hierarchy и подходящие щелчки по мешам в Scene View
меняют один и тот же выбор. Inspector следует за ним, если не заблокирован.
Выбор в Hierarchy не кадрирует камеру автоматически; при необходимости используйте
**Frame selection**. При переключении вкладок восстанавливается выбор каждого документа.
Простой перевод фокуса на инструмент не активирует другой документ.

Открытие превью PNG/GLB очищает активную цель документа. Hierarchy больше не показывает
исходный граф, а у незаблокированного Inspector нет исходного узла для просмотра.
Сцена предпросмотра модели не выдаётся за исходный документ. Вернитесь на вкладку документа,
чтобы восстановить его выбор.

## Сеансы исходников и внешние изменения {#source-sessions-and-external-changes}

Первое поддерживаемое открытие принимает ограниченный набор исходников, общий для следующих
открытий. Уже открытые документы используют принятые данные и выбор, не перечитывая диск.
Перед первым открытием другого принятого исходника редактор повторно проверяет его байты
и идентичность. Неудачное открытие сохраняет прежний активный документ и выбор.

**Refresh sources** обновляет списки Assets, а не принятые документы. Новые документы
вне принятого набора требуют повторного открытия проекта. После внешнего изменения
исходников откройте проект заново; для превью также пересоберите соответствующую поставку
ресурсов и перезапустите редактор с ней. Автоперезагрузка, согласование изменений
и сценарий Save/Discard отсутствуют. См. [подготовку Scene View](scene-view.md#prepare-resources).

Физический ввод, буфер обмена ОС, IME, экранные дикторы и работу с разным DPI ещё нужно
проверять на каждой платформе; полная сертификация для настольных систем не завершена.

Для проверки перейдите к [Нативным сценариям](../testing/native-scenarios.md),
а за аргументами запуска — к [справочнику CLI редактора](../cli/editor-and-assets.md).
