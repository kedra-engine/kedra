# Inspector

Inspector показывает эффективные значения исходных компонентов выбранного узла.
Выберите узел в [Hierarchy](hierarchy.md) или поддерживаемым выбором меша
в [Scene View](scene-view.md). Для просмотра исходника не нужны подходящая поставка
ресурсов рендерера или успешный кадр превью.

Панель работает только для чтения. Значения не являются текущим игровым состоянием,
а вычисленная компоновка UI не подставляется вместо исходной. Inspector не перечисляет
вспомогательные компоненты рендерера и компоненты, созданные компилятором, только потому,
что они есть в превью.

## Просмотр выбранного узла

В заголовке показано имя узла, а разделы компонентов названы по зарегистрированным ключам
исходников. Раскройте компонент или значение, чтобы увидеть вложенные поля, если они
доступны; сверните их, чтобы освободить место. Для просмотра остальных разделов
прокрутите область свойств.

Представление через рефлексию поддерживает примитивы/строки, именованные структуры, кортежи,
кортежные структуры, активные варианты enum и ограниченную структуру коллекций. Числа
сохраняют исходную точность; вращение не преобразуется автоматически в углы Эйлера.
Неизвестные/непрозрачные формы и отсутствующие возможности показывают тип и причину,
а не вымышленные контролы редактирования. Коллекции показывают начальный ограниченный
сегмент, без постраничной навигации.

Текст свойств допускает нативное выделение в режиме чтения, где это поддерживается.
Выделение не разрешает ввод нового значения. Полная поддержка буфера обмена ОС,
копирования/вставки и IME не сертифицирована; панель не служит средством экспорта полных значений.

## Меню группы

Действия Inspector находятся в меню **…** его dock-группы, когда Inspector активен.
Контекстное меню редактирования компонентов не реализовано.

| Команда | Результат |
| --- | --- |
| Search properties | Открыть поле поиска свойств и установить в нём фокус. |
| Lock Inspector | Продолжать просмотр текущей исходной цели, пока выбор в других панелях меняется. |
| Unlock Inspector | Снова следовать за выбором активного документа. |
| Use default reflected view | Обойти специализированные представления и показать структуру рефлексии. |
| Use custom presentations | Вернуть выбор зарегистрированных представлений, где они есть. |
| Toggle source details | Показать/скрыть путь и контекст просмотра исходника только для чтения. |

Lock предлагается только при наличии цели или для снятия уже установленной блокировки.
Закрепляется идентичность, а не замороженная копия значений. Команда не блокирует документ
от изменений и не меняет выбранный узел Hierarchy. Если цель становится недоступной,
панель сообщает об этом, не переходя на другой одноимённый узел.

Панель исходников сейчас использует реестр представлений по умолчанию: меню custom
presentations не загружает плагины проекта и не гарантирует специальный виджет для каждого
компонента. Default reflected view — запасной способ просмотра, не преобразование формата.
Панель передаёт команды раскрытия и сворачивания только деревьям компонентов верхнего уровня.
Вложенные специализированные представления должны сами обрабатывать команды для своих
внутренних деревьев. Расширения Inspector, определяемые проектом, недоступны.

## Поиск без смены выбора

Вызовите **Search properties** или Ctrl/Cmd+F с фокусом в Inspector. Поиск сохраняет
идентичность объекта и контекст компонентов/предков. Он не выбирает другой объект
и не редактирует значения. Закройте строку её кнопкой или Escape с фокусом в панели;
закрытие очищает запрос.

Поиск сопоставляет подписи свойств и показанные превью значений без учёта регистра,
в пределах бюджетов просмотра. Это не поиск по всем значениям проекта.

Поле принимает до 256 символов и отклоняет управляющие символы. Раскрытие, поиск,
блокировка и режим default/custom локальны для этого представления Inspector.
Hide/Reopen, Float/Redock и разворачивание сохраняют панель, а не монтируют ещё один
Inspector с независимым рабочим пространством исходников.

## Пример: эффективное переопределение

Подготовка тестового проекта описана в [первом документе](../getting-started/first-document.md).
[Пример композиции](../scenes/composition.md) объясняет используемое переопределение.

Откройте `assets/Inspector/Main.prefab.ron` из тестового проекта в репозитории:

1. Сначала в Hierarchy выбран **Main**. Его `ui.editable` описывает настройки исходника,
   но не превращает поле Inspector в редактируемое.
2. Выберите вложенный узел **Repeated name**. При необходимости раскройте `ui.caption`.
3. Значение `text` равно `Override 日本語`, а не исходному `Inherited 日本語` дочернего префаба.
   Inspector читает эффективную композицию, включая переопределение экземпляра.
4. Вызовите **Lock Inspector**, затем откройте `Inspector/Other.prefab.ron` в Assets.
   Активный документ изменится, но Inspector сохранит **Repeated name**.
5. Найдите `text`, чтобы сузить свойства, не потеряв закреплённую цель.
6. Вызовите **Unlock Inspector**, чтобы снова следовать активному документу.
   Значение надписи другого примера — `Other source`.

Тестовые файлы сохраняют Unicode-текст без изменений. Отрисовка каждого глифа зависит от
доступных шрифтов; работу шрифтов и IME ещё нужно проверять.

## Пустые, недоступные и ограниченные представления

| Состояние | Значение / следующий шаг |
| --- | --- |
| Подсказка выбрать узел | Откройте документ и выберите корень/потомка; превью отдельных ассетов не даёт исходную цель. |
| Нет исходных компонентов | Узел корректен, но не содержит значений компонентов для показа. |
| Target unavailable | Область исходников, компиляция, ревизия или узел больше не подходят для просмотра. |
| Нет совпавших свойств | Измените или очистите поиск; выбор не менялся. |
| Search incomplete / предел представления | Часть значений пропущена из-за бюджетов просмотра; результаты неполны. |
| Ограничение представления ссылки | Ссылку на объект исходного документа пока нельзя отобразить с сохранением её смысла; не считайте показанное значение явно заданным в исходнике `None` или постоянным номером runtime-сущности. |

Текущие пределы: глубина 32, 128 элементов коллекции, 2048 обнаруженных строк за перестроение
и 4096 скалярных значений Unicode в превью значения. Усечение не меняет исходники
и не является полным копируемым значением. Поиск использует те же ограничения.

Активных действий Add component, Reset, Apply/Revert, выбора/перехода к ассету,
редактирования полей, undo/redo изменений исходников и Save нет. Отличие API авторинга
от возможностей редактора описано в разделе
[Изменение исходников и Save](../scenes/source-editing.md).
