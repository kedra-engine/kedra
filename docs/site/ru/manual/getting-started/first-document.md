# Открытие и изучение первого документа

Сначала [откройте Kedra Test Project](launch-editor.md).
Проект входит в репозиторий и находится по пути `tests/fixtures/test_project`.
Он содержит авторские демонстрационные и тестовые данные, а не стартовый шаблон игры.

**Не меняйте канонический тестовый проект.** Просматривайте его без изменений. Перед опытами
с внешним изменением исходников скопируйте весь проект в новый личный каталог, включая
`kedra.toml`, `assets/` и все существующие `.meta` sidecar-файлы. Открывайте и собирайте
копию. Копирование сохраняет идентичности, а не генерирует идентичность нового проекта.

## 1. Найдите префаб в Assets

1. Выберите вкладку **Assets**.
2. Перейдите в корень ассетов проекта через цепочку пути или дерево папок браузера.
3. Найдите **Cuboid.prefab.ron**. При необходимости переведите фокус в Assets, нажмите
   Ctrl+F в Windows/Linux или Cmd+F в macOS и введите `Cuboid`.
   Поиск работает только в текущей папке.
4. Один раз щёлкните по исходнику, чтобы выбрать его.

На диске файл находится в `tests/fixtures/test_project/assets/Cuboid.prefab.ron`, а в
каталоге источников проекта — по пути `game://Cuboid.prefab.ron`. Пути внутри проекта
показываются относительно него, например `assets/Cuboid.prefab.ron`.
Соседний `.meta` sidecar-файл не отображается отдельным элементом браузера.

## 2. Откройте выбранный исходник

Управление папками, поиском и фильтром описано в [Asset Browser](../editor/asset-browser.md).

Дважды щёлкните по **Cuboid.prefab.ron** или нажмите Enter, когда фокус находится на нём.
Другой вариант — **Open selected source** в меню группы Assets.
Один щелчок выбирает элемент браузера, но не активирует документ.

Ожидаемый результат: вкладка документа **Textured cuboid** и соответствующее дерево
Hierarchy. Первое открытие принимает весь набор документов проекта в общее рабочее
пространство только для чтения, поэтому может занять больше времени, чем выбор уже
открытой вкладки. Повторное открытие возвращает к существующему виду и сохранённому выбору.

Без `--project-assets` Scene View может сообщить об отсутствии поставки ресурсов.
При этом можно изучать принятые исходные узлы и компоненты без отрисовки.

## 3. Выберите узел и изучите компоненты

1. Выберите вкладку **Hierarchy** и щёлкните по **Textured cuboid**, корневому узлу префаба.
   В этом префабе один узел; дерево из одной строки — ожидаемый результат.
2. Выберите **Inspector**. Он следует за выбранным исходным узлом активного документа.
3. Раскройте разделы компонентов, чтобы прочитать авторские значения. Найдите исходные
   ключи компонентов `scene.primitive`, `scene.surface` и `scene.transform`.

В тестовом проекте описан кубоид с размером `(2.0, 2.0, 2.0)`, смещением
`(0.0, 1.0, 0.0)` и ссылкой на текстуру поверхности `game://checker.png`.
Компоненты и поля доступны только для чтения. Вы читаете скомпилированные исходные значения,
а не меняете трансформацию работающего объекта и не сохраняете изменённый документ.

Если инструмент скрыт, откройте **Panels** в заголовке рабочего пространства. Меню
перечисляет существующие виды: **Show …** для скрытых и **Select …** для видимых.
Если Inspector остаётся на другом объекте, выберите **Unlock Inspector** в меню его группы.
Если значения скрывает поиск свойств, очистите строку поиска.

## 4. Откройте сцену с составной иерархией

Навигация и просмотр свойств описаны в [Hierarchy](../editor/hierarchy.md) и
[Inspector](../editor/inspector.md), расположение панелей — в
[Рабочем пространстве редактора](../editor/index.md).

Вернитесь в корень ассетов, очистите поиск браузера и тем же действием откройте
**Composed.scene.ron**. Активным документом станет **Composed spatial scene**.
Теперь Hierarchy показывает локальные узлы и вложенные экземпляры префабов, а не просто
файлы на диске.

Выберите **Warm sphere** в Hierarchy и изучите компоненты. Можно также выбрать вложенный
узел **Textured cuboid**, чтобы изучить префаб в составе этой сцены.
Смена вкладки документа переключает активную иерархию; выбор в браузере сам по себе — нет.
Основные понятия описаны в разделах [Сцены и префабы](../scenes/index.md) и
[Композиция и переопределения](../scenes/composition.md).

## Дополнительно: проверьте отрисовку превью

Если вы запустили редактор с соответствующей поставкой проекта по
[инструкции запуска](launch-editor.md),
Scene View может отобразить поддерживаемое пространственное и UI-содержимое. В составной
сцене есть кубоид, **Warm sphere**, сгенерированная модель, освещение и экземпляр префаба HUD.
Дождитесь готовности зависимостей и кадра: открытая вкладка ещё не означает отрисованный кадр.

Пути, идентичности и байты исходников должны соответствовать поставке. Успешная отдельная
команда `assets verify` доказывает целостность поставки, но не её соответствие исходникам
после внешних изменений. Для смены привязки нужен перезапуск с новой соответствующей поставкой.
Это изолированное превью только для чтения: оно не запускает исполняемый файл игры из
тестового проекта, не выполняет скрипты проекта и не предоставляет Play.

## Восстановление без изменения тестового проекта

Управление камерой и выбором в превью описано в [Scene View](../editor/scene-view.md).

- **Файл не найден:** вернитесь в корень ассетов и очистите поиск. Поиск в подпапке не
  охватывает весь проект. В новом пустом проекте нет `Cuboid.prefab.ron`.
- **Список устарел или не читается:** выберите **Refresh sources** в меню группы Assets или
  нажмите F5. Неудачное обновление сохраняет предыдущий список как устаревший и блокирует
  активацию до восстановления.
- **Открытие отклонено:** прочитайте диагностику. Один неверный документ в другом месте
  набора может отклонить первый приём. Сохраните канонические файлы; исправляйте полную
  чистую копию. Ошибка открытия не подменяет уже активный документ запасной сценой.
- **Внешние изменения не видны:** повторное открытие вкладки не перечитывает диск.
  Заново откройте проект для приёма свежего набора исходников; для отрисовки пересоберите
  поставку и перезапустите редактор.
- **Исходные данные доступны, превью — нет:** проверьте явный проект и пути обеих поставок,
  затем см. [диагностику ассетов][preview-errors].

Нативный ввод и отрисовку ещё нужно проверить на вашей машине. Визуальное редактирование,
сохранение документов и Play недоступны.
